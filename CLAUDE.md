# CLAUDE.md

## Rules

### No personal information or real-world names

- Never use personal information (names, email addresses, phone numbers, addresses, account IDs, etc.) in code, tests, fixtures, sample data, documentation, or screenshots.
- Never use the titles of real books or the names of real authors. Use clearly fictional placeholders instead (e.g. "Sample Book", "Example Author").
- This applies to commit messages, PR titles, and PR descriptions as well. Do not include any of the above in them.

### Comments and documentation

- Do not write excessive explanations in code. Keep comments minimal.
- Put explanations in commit messages instead of in the code.
- Do not create a `docs` folder (or any similar folder) to store information.
- Record background, context, and the history of decisions in commit messages and PR descriptions.

### Commits and pull requests

- Write commit messages, PR titles, and PR descriptions in English by default.
